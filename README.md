My engineering principles

01 — Solve the right problem

Before choosing a framework, model, or architecture, understand the problem and the people experiencing it.

02 — Make complexity invisible

Good engineering can be sophisticated underneath while remaining simple on the surface.

03 — Build for change

Systems should be designed with evolution in mind—not just today's requirements.

04 — Measure what matters

Performance, model quality, reliability, cost, and user experience should be measurable.

05 — Use AI intentionally

AI should create meaningful value—not simply be added because it's the latest technology.
